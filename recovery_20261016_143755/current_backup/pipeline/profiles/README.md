# 参数管理入口

当前在线后端的工程默认值只在 `default.json` 维护。加载和完整性校验统一由上一级目录的 `configuration.py` 负责。自定义在线 JSON 可以只填写需要覆盖的有效参数，未填写项从本目录的 `default.json` 补齐。权威默认配置本身缺少有效参数时会报错，不会偷偷采用旧类的默认值。

|配置区域|参数含义与单位|
|---|---|
|`tracking`|存活概率及参考周期（秒）、加速度谱密度 `q_a`（投影坐标²/秒³）、检测概率、测量协方差（像素²）、单次预测最大间隔（秒）与来源|
|`undetected_population`|两类未探测对象的初始期望数量、出生率（对象/秒）、目标速度标准差（rad/s，近光轴投影坐标）、来源|
|`background`|未知恒星的逐次持续概率、检测概率、测量协方差（像素²）与来源|
|`clutter`|每帧期望杂波数量与来源；图像观测范围由输入相机尺寸生成，仅记录在生效快照中|
|`lifecycle`|确认概率、确认窗口和最少支持帧数、候选低概率及退出时间窗（原始帧）、休眠时间（秒）、可靠关联与可见性概率、每组休眠轨迹预算和策略标识|
|`inference`|门控概率、每组保留假设数、候选/节点/边/搜索上限、内存上限（字节）、单帧耗时上限（秒）；运行方式固定为有界近似联合推断|
|`input_metadata`|相机内参（像素）、时间单位和帧周期、帧/时间原点、列映射、姿态方向、越界处理、输入行数限制；`max_rows` 同时限制原始表和规范化输入各表的读取|
|`calibration`|畸变模型和系数、像素偏斜、归一化半径、相机反解误差（像素）与迭代次数、标定来源|
|`geometry`|固定投影坐标系的有效角度范围（度）；同时用于未探测群体与结果输出的投影|
|`bootstrap`|公共星表绑定模式、已知恒星检测概率与出生模型说明；已知恒星测量协方差明确沿用 `tracking` 的协方差|
|`reporting`|明细级别 `compact/full`、是否写逐帧 JSON|
|`classification`|`enabled` 开启同一物体内的固定源/运动源竞争；默认关闭，可用 `class_mixture_trial.json` 试验配置开启|
|顶层字段|配置版本、引擎、星表路径/星等上限及请求帧；生效快照另记录输入绑定结果与来源|

同值不等于冗余：目标检测概率、未知恒星检测概率、已知恒星检测概率分别属于不同物理来源，可独立标定。已删除在线默认配置中重复表达这些固定值的 Gamma/Beta 环境先验，以及旧出生网格、求积阶数、背景数量限制、旧模型年龄时限和归档身份搜索预算。错拼、不支持或闲置的在线参数会明确报错。

`profile_id`、配置/策略版本、各处的 `parameter_provenance`、标定状态及模型范围说明是复现和审计记录，不是可调阈值。节点、边和分量预算通过统一预算检查器动态读取，仍实际限制计算量。

## 每次运行的记录

在线轨迹退出规则：存在概率连续 6 帧严格低于 0.1 时归档并移出后续预测和关联；恢复到大于等于 0.1 时计数清零，帧号中断时重新计数。已确认轨迹同样适用，历史确认标记和退出时的条件状态保存在归档中。参数沿用 `lifecycle.candidate_low_probability`、`candidate_low_frames` 和 `enable_candidate_pruning` 的既有配置名称；`candidate_deadline_frames` 只用于未确认候选的超期标记，不再阻挡低概率退出。归档文件沿用 `retired_candidates.json`。这是在线状态的近似移除，不表示物理目标必然消失。

默认值适用于新运行；显式指定旧 `effective_prior.json` 时仍采用该文件内的阈值。

当前运行模型版本为 `v2.2-factorized-class-mixture-2`，检查点格式为 `factorized-class-mixture-5`。检查点绑定包含版本和类别配置，旧版本检查点需通过重新运行输入建立新状态。

- `effective_prior.json`：完整生效参数，含当前数值策略快照和实际输入相机/时间体系 `bound_input`。既支持原始表格入口，也支持标准化输入目录入口。
- `tracking_summary.json`：相同的模型配置及运行结果。
- `entrypoint.json`：公共入口使用的源文件、配置路径及校验值、命令执行选项（包括 `verbose` 和 `log_every`）。

`initial_timestamp_s`、`stars` 和 `clutter.bounds_px` 分别来自首帧时间、星表可见并集与实际相机尺寸，不是可调默认项。普通配置填写这些字段会明确报错，避免参数被绑定过程静默覆盖。已绑定的 `effective_prior.json` 带有 `bootstrap_definition`，会保留并校验这些派生字段，以支持原样复现。

投影坐标基底和条件状态由输入或概率递推产生，不作为另一套手工默认值维护。外部 metadata 明确覆盖输入配置后，快照记录实际使用的元数据。已有输出快照不随默认配置修改而改写。

## 数值策略

`v2/numerical_policy.py` 集中维护概率和检查点归一化容差、矩阵/单位向量误差倍数、高斯窗口积分容差与分段、窗口内部近似界限及绘图数值容差。这些是实现精度规则，不是目标筛选阈值；版本和值写入运行快照，不允许用 JSON 悄悄覆盖。

旧后端字段和开发工具参数不进入在线可调参数表。含旧字段的配置会报出不支持字段，不会静默忽略。出生率、噪声、确认门槛和关联预算的既有值未因参数管理改造而重新调优，未校准参数的来源状态仍保留。

## 类别竞争试验

运行 `run.ps1 -d 点目标筛选实验数据.xlsx --config space_target_detection/pipeline/profiles/class_mixture_trial.json` 开启。该试验改变类别竞争，并在观测前将未检测群体重投影到当前视轴切平面，修正出生状态的远距离线性化偏差；不同时调整星等上限、测量误差或过程噪声数值。坐标运输包含速度及位置/速度协方差交叉项，不使用当前检测建立先验。

新生物体的固定源与运动源状态属于同一互斥类别混合，两个类别随观测持续竞争；`top_k` 裁剪物体关联历史时，不会在同一历史内删掉某个类别。物体存在概率与目标类别概率分别输出。固定源充分占优时成熟度为 `FIXED_SOURCE`，报表显示恒星；历史确认不会直接恢复目标成熟度。

`T:` 来源前缀在试验模式中只表示持久物体身份，物理类别请读取五类来源概率及 `Target_Model_Probability` / `Static_Model_Probability`。检测结果仍区分已知恒星、未知恒星、已有目标、新生目标和杂波。CSV 的 `target_model_probability`、`static_model_probability` 为给定物体存在的类别概率；`target_posterior`、`star_posterior` 则是当前检测的来源概率，两者语义不同。

报表 `formal_confirmed` 和 `confirmed_targets` 反映当前确认，`target_confirmed_ever` / `ever_formal` 和 `historically_confirmed_tracks` 记录历史确认。轨迹被拒绝、截断或改判后不会仅凭曾经确认继续列入当前正式目标图。

本方案仍使用原来的仿射似然、有限门控与 PPP 近似，不代替相机/姿态误差标定，也未增加归档轨迹重识别。类别开启时要求两类检测概率在 (0,1)、两类存活概率为正。完整序列的精度与资源验证完成前保持试验开关。
